# Безпека Поруч — PWA

Ця папка — готова PWA-обгортка над твоїм Google Apps Script додатком.
Вона відкриває сторінку скрипта всередині (iframe), додає можливість
"встановити" застосунок на телефон/комп'ютер та базовий offline-екран.

## Що всередині
- `index.html` — головна сторінка, вбудовує твій Apps Script лінк
- `manifest.json` — опис PWA (назва, іконки, кольори)
- `service-worker.js` — кешує лише оболонку (не дані з таблиці)
- `icons/` — іконки застосунку (заглушки, можна замінити своїми)

## Крок 1. Заміни лінк (за потреби)
У файлі `index.html` знайди рядок:
```html
src="https://script.google.com/macros/s/.../exec"
```
Це вже твій лінк, якщо він не зміниться — нічого робити не треба.

## Крок 2. Виклади на GitHub

1. Створи новий репозиторій на GitHub, наприклад `bezpeka-poruch`.
2. Заливай всі файли з цієї папки в корінь репозиторію:
   ```bash
   cd bezpeka-poruch
   git init
   git add .
   git commit -m "PWA обгортка"
   git branch -M main
   git remote add origin https://github.com/ТВІЙ_ЛОГІН/bezpeka-poruch.git
   git push -u origin main
   ```
3. У репозиторії відкрий **Settings → Pages**.
4. У розділі "Build and deployment" вибери:
   - Source: **Deploy from a branch**
   - Branch: **main**, папка **/ (root)**
5. Збережи. Через 1-2 хвилини сайт зʼявиться за адресою:
   ```
   https://ТВІЙ_ЛОГІН.github.io/bezpeka-poruch/
   ```

## Крок 3. Встанови як застосунок
- **Android/Chrome:** відкрий адресу сайту → меню (три крапки) → "Встановити застосунок" / "Додати на головний екран".
- **iPhone/Safari:** відкрий адресу → кнопка "Поділитись" → "На екран Домівки".
- **Десктоп (Chrome/Edge):** іконка встановлення (⊕) у адресному рядку.

## ⚠️ Важливий нюанс
Google Apps Script деколи блокує показ своєї сторінки в `<iframe>` залежно
від налаштувань розгортання. Якщо після заливання на GitHub Pages
сторінка показує білий екран замість застосунку:

1. Відкрий Apps Script проєкт → **Deploy → Manage deployments**.
2. Перевір, що тип розгортання — **Web app**, доступ: **Anyone** (не "Anyone with Google account", якщо не потрібна авторизація).
3. Якщо все одно блокує — напиши мені, зробимо інший варіант:
   PWA буде звертатись напряму до Apps Script як до API (через `fetch`)
   і сама будувати інтерфейс, без iframe — це надійніший, хоч і довший шлях.

## Оновлення даних
Дані (сама таблиця) підтягуються напряму з Google Script при кожному
відкритті — сервіс-воркер їх не кешує, тому користувач завжди бачить
актуальну інформацію (за наявності інтернету).
